# 07 — Provide verified bilingual Recipe Guides

**What to build:** Let Members and Cooks open trustworthy Recipe Guides from a
planned meal, understand whether the content is verified or an AI draft, scale
dependable quantities, and play cached English or Hindi instructions on demand.

**Blocked by:** 05 — Edit the Weekly Meal Plan from either role; 06 — Add
private photo and voice-note Chat.

**Status:** ready-for-agent

- [ ] The initial recipe library contains a focused human-reviewed set of
      familiar North and South Indian home meals.
- [ ] Every Recipe Guide visibly distinguishes verified content from an
      editable AI-generated draft.
- [ ] Dependable ingredients scale deterministically from the base Serving
      Count, while salt, oil, spices, water, and judgement-based ingredients
      remain approximate.
- [ ] Only dependable quantities feed Estimated Pantry and grocery
      calculations.
- [ ] Recipe steps render in English or Hindi according to the Cook's selected
      language.
- [ ] On-demand audio is generated behind the authenticated server boundary,
      cached by recipe version/language/voice, and never exposes provider
      credentials.
- [ ] Recipe text provides the accessible equivalent of audio, and playback
      controls work with VoiceOver and TalkBack.
- [ ] Representative Hindi recipes pass a human pronunciation review before
      production release.
